项目名称 Life Map

项目简介

本项目是一个基于 HTML、CSS 和 JavaScript 开发的交互式人生模拟体验程序。

用户可以创建自己的角色，通过不同人生阶段的选择体验虚拟人生发展过程，包括童年、学习、职业、人际关系、生活事件等多个方面。

项目通过交互式选择、动态页面更新以及多媒体元素增强用户体验。

# 项目主要功能介绍

## 1. 角色创建系统

用户可以选择角色外观和基础信息，系统会根据用户选择生成对应人物。

## 2. 人生模拟系统

程序按照年龄阶段推进：

- 儿童时期
- 青少年时期
- 大学阶段
- 工作阶段
- 成年生活
- 老年阶段


每个阶段都会产生不同事件。

例如：

- 学习选择
- 职业选择
- 人际关系
- 财富管理
- 生活决策


## 3. 属性变化系统

用户的选择会影响：

- 智力
- 健康
- 财富
- 幸福感
- 社交能力


最终根据综合属性生成不同人生结局。
